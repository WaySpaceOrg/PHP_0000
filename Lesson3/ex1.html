ตัวแปร JavaScript

ตัวแปรใช้สำหรับเก็บข้อมูล เช่น ข้อความและตัวเลข โดย const ใช้กับค่าที่ไม่กำหนดใหม่ และ let ใช้กับค่าที่เปลี่ยนแปลงได้

const shop = "ร้านกาแฟแมวเหมียว";
let cups = 5;
cups = cups + 1;
console.log(shop);
console.log(cups);

ผลลัพธ์จากตัวแปร

ชื่อร้าน:

จำนวนแก้วเริ่มต้น: 5 แก้ว

หลังเพิ่มอีก 1 แก้ว: แก้ว

💡 ลองเปิด Developer Tools แล้วเลือก Console เพื่อดูผลจากคำสั่ง console.log()
