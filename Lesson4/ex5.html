  1. site map ต้องอยู่ในไฟล์ชื่ออะไร
    ตอบ: index.html
  2. แท็ก nav ของ site map ต้องมี id อะไร
    ตอบ: sitemap
  3. รายการซ้อนใน site map ใช้แท็กอะไร (พิมพ์แค่ชื่อแท็ก ไม่ต้องมี < >)

  4. ใต้รายการหน้าแรกใน site map ต้องมีกี่รายการ (ตอบเป็นตัวเลข)
    ตอบ: 4
  5. หน้าเกี่ยวกับฉันต้องเป็นไฟล์ชื่ออะไร
    ตอบ: about.html
  6. รายการข้อมูลส่วนตัวต้องอยู่ใน ul ที่มี id อะไร
    ตอบ: profile
  7. ข้อมูลส่วนตัวต้องมีอย่างน้อยกี่รายการ (ตอบเป็นตัวเลข)
    ตอบ: 4
  8. ในไฟล์ about.html ลิงก์กลับหน้าแรกต้องเขียน href ว่าอะไร
    ตอบ: index.html
  9. ใส่เบอร์โทรศัพท์ในหน้าเกี่ยวกับฉันได้หรือไม่ (ตอบ ได้ หรือ ไม่ได้)
    ตอบ: ไม่ได้
